# Habitat Home Collection

HABITAT — AMnova Home & Lifestyle Theme Template

Create a reusable ecommerce storefront theme called:

HABITAT

The template is intended for merchants selling:

home goods

kitchen products

smart kitchen gadgets

portable appliances

fans and cooling products

home comfort products

blankets

organization products

lifestyle accessories

practical household products

This is a reusable category theme, not a single fictional brand.

CREATIVE DIRECTION

Create a warm contemporary lifestyle storefront inspired by:

modern interiors

natural materials

architectural photography

everyday rituals

functional design

Scandinavian/Japanese-inspired interiors

contemporary product design

The experience should feel:

warm

useful

refined

calm

modern

tactile

Do not make it look like a furniture catalog.

Do not make it look like Amazon.

Do not make it look like a generic Shopify template.

COLOR

Use:

warm ivory

sand

stone

charcoal

muted clay

natural green

The palette must remain restrained.

HOMEPAGE

Build:

AnnouncementBar

Header

Hero

Featured Collection

New Arrivals

Category Grid

Product Showcase

Lifestyle Editorial

Product Benefits

Promotional Banner

Testimonials

Newsletter

Footer

HERO

Create an editorial home/lifestyle composition.

Show products naturally inside an environment.

Avoid floating product cutouts whenever possible.

The product should feel physically integrated into the scene.

CATEGORY EXPERIENCE

Support categories such as:

Kitchen

Comfort

Cooling

Smart Home

Organization

Lifestyle

These should be merchant-configurable.

PRODUCT EXPERIENCE

Support:

product image

name

price

variants

availability

quick add

Add to Cart

product details

reviews

EDITORIAL

Create sections where products can be presented in context.

Example:

Designed for everyday living.

Large image + text + product references.

AMNOVA

Use reusable theme sections.

Conceptually support:

Hero

FeaturedCollection

ProductGrid

CollectionGrid

EditorialSplit

ImageBanner

ProductFeature

Testimonials

Newsletter

Footer

Semantic catalog references:

catalog:new-arrivals

catalog:collection:<handle>

No merchant UUIDs.

No backend.

No custom theme engine.

CONTENT SAFETY

Do not invent:

energy savings

cooling performance

medical benefits

safety certifications

product guarantees

fake reviews

Merchant-provided claims only.

ASSETS

Use local/self-contained assets.

No:

Unsplash

Pexels

Google Fonts

external image CDNs

RESPONSIVE

Design specifically for:

desktop

tablet

375px

Mobile must be intentionally composed.

PROCESS

Do not generate the complete storefront.

Stage 1:

Establish the visual system.

Stage 2:

Build:

Header + Hero + Featured Collection

Then stop for review.
